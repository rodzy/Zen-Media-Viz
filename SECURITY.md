# Security Policy

Zen Media Viz runs with browser-chrome privileges inside Zen, so security problems matter even though the mod is small.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/rodzy/Zen-Media-Viz/security/advisories/new). Include:

- what the problem is and what an attacker could do with it,
- steps to reproduce (for example, a page whose media metadata triggers it),
- your Zen, Sine and Zen Media Viz versions.

You can expect an acknowledgement within a week. Once a fix is released, the advisory will be published with credit to you unless you prefer otherwise.
